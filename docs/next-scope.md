# Explicitly deferred scope

The following work is outside declared V1 and is not required to close the current implementation: internet-facing identity/SSO, Kubernetes operators, multi-region consensus, tool sandboxing, secrets management, retention/DSAR workflows, a visual workflow editor, integration marketplace, n8n compatibility, RelayForge adapter, OpenTelemetry tracing, and production capacity/SLO qualification.

These items must not be presented as incomplete V1 work unless the product contract changes. Deployment-specific penetration testing, production load/capacity observation and organization-specific compliance controls remain future external evidence lanes rather than hidden code gaps.
