# Code-complete criteria

For declared V1, code-complete requires working state/DAG semantics, durable PostgreSQL claims/leases/fencing/recovery, retries/timeouts/cancellation, checkpoints and explicit recovery compatibility, tool/provider/agent execution, signals, ordered events, HTTP/SSE control plane, SDK, examples, migrations, bounded configuration, CI, adversarial tests, benchmarks and required documentation.

It does not require deferred hosted-product features listed in `next-scope.md`.
